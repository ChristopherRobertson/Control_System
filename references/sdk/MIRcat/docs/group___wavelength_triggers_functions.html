Retrieves the parameters for an advanced sweep for a specific QCL channel.

Attention

Parameters
bQclThe QCL channel (indexed from 1).
[out]chStartWaveThe start wavelength/wavenumber (same units as in MIRcatSDK_GetAdvancedSweepParams).
[out]chStopWaveThe stop wavelength/wavenumber (same units as in MIRcatSDK_GetAdvancedSweepParams).
[out]useChannelDetermines whether the channel is used during the sweep.
See also
Units
Returns
Return Code indicating the status of retrieving the advanced sweep channel parameters.
Return values
MIRcatSDK_RET_SUCCESSif the system successfully read and retrieved channel parameters.
MIRcatSDK_RET_PASSED_NULL_POINTERif any of the out parameters are null pointers.
MIRcatSDK_RET_NOT_INITIALIZEDif the MIRcat controller is not yet initialized.
MIRcatSDK_RET_COMM_ERRORif the MIRcat controller is unable to read sweep parameters from the system.
MIRcatSDK_RET_QCL_NUM_OUTOFRANGEif the inputted bQcl value is out of scope of the number of channels available.

uint32_t MIRcatSDK_ReadWriteAdvancedSweepParams ( bool fWrite)

Allows users to read/write parameters for the advanced sweep.

Attention
Users must use the ReadWrite function to read/write in hardware. The Set and Get functions alone are not enough.
Parameters
fWriteDetermines whether the user is reading or writing. (Writing being true; reading being false)
Returns
Return Code indicating the status of reading/writing parameters for the advanced sweep.
Return values
MIRcatSDK_RET_SUCCESSif the system can successfully read/write parameters for the sweep-advanced scan.
MIRcatSDK_RET_NOT_INITIALIZEDif the MIRcat controller is not yet initialized.
MIRcatSDK_RET_START_SWEEP_ADVANCED_SCAN_FAILUREif the system fails to start/access a sweep-advanced scan.
