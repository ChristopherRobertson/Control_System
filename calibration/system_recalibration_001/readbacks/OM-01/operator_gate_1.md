# OM-01 operator gate 1 - power-meter pre-use inspection

Status: **SENSOR CONDITION AND DARK COVER PASS; COVERED PREVIEW REJECTED FOR RANGE; NO OPTICAL EMISSION**

Purpose: establish the meter/head physical condition and an undisturbed dark
baseline setup before any setting change or optical measurement.

The operator action is supplied conversationally one step at a time. Do not
arm either laser, open the MIRcat shutter, move final experiment optics, or
place the sensor in any beam for this gate.

Acceptance requires the meter and sensor identities to agree with the live
readback, the DB15 and USB connections to be secure, the absorber/aperture to
show no visible contamination or damage, and the sensor to be positioned away
from airflow/heat disturbances with an opaque non-contact cover available.

Any mismatch, damaged/contaminated absorber, loose connector, error indicator,
unexpected reading behavior, ownership conflict, or unsafe routing stops the
gate.
