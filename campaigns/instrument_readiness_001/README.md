# Instrument readiness 001

This campaign unifies the calibration, characterization, independent validation,
reporting, and promotion work required before HRP. `master_sequence.md` is the
human-readable execution view; `../registry/phase_registry.yaml` is the sole
machine-readable phase/dependency authority.

Legacy detailed procedures remain linked by registry `plan` fields. Completed
evidence remains linked by `evidence_key`; it is not copied or renamed. Optional
cryogenic MbCO work is a separate campaign and cannot block this core path.
