# Documentation instructions

The root README covers setup, repository boundaries, storage and verification.
`docs/README.md` indexes current operator instructions in `operating_procedures/`.
`instrument/README.md` explains runtime resources and parameter selection.

Write self-contained instructions for the current application. State actual UI
actions, prerequisites, ownership, output routing, cancellation, restoration,
native preservation and scientific limitations. Link to current files or supplier
references; include essential operational information directly where needed.
Do not require a particular research run to explain or use a software workflow.

Keep native schema compatibility clear without changing source records. Separate
nominal electrical command timing and modeled response from measured optical
calibration. Never infer qualification or hardware authorization from passing
software checks, metadata or the presence of configuration files. Keep historical
test counts and development narratives out of operating instructions.
