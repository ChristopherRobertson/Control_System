uint32_t MIRcatSDK_PointingImportCalTable ( uint8_t chan,

uint8_t wlUnits,
uint8_t laserMode,
char * tableName,
float * wavelengths,
int32_t * xCal,
int32_t * yCal )

Imports the calibration table for a specified channel/table number.

Attention
Table number 0 is typically used as the factory calibration table. This function does not allow the user to import a calibration table as table number 0 to prevent the factory calibration from being overwritten.
Parameters
chanLaser channel for this calibration table (index starting at 1).
tableNumTable number for this calibration table. There are up to MIRCATSDK_POINTING_MAX_TABLES_PER_CHANNEL tables per channel (indexed 0-7).
numEntriesThe number of calibration entries in this calibration table.
wlUnitsThe wavelength units used for this calibration table (see cal table format for wavelength units; MIRcatSDK_UNITS_MICRONS and MIRcatSDK_UNITS_CM1).
laserModeLaser mode for this calibration table (see cal table format for laser mode units).
tableNameA name for the calibration table (max character length of 31).
wavelengthsArray of wavelengths for this calibration table. The size of the array should match numEntries.
xCalArray of x calibration offsets for this calibration table. The size of the array should match numEntries.
yCalArray of y calibration offsets for this calibration table. The size of the array should match numEntries.
Returns
Return Code indicating the status of importing the calibration table.
Return values
MIRcatSDK_RET_SUCCESSif the calibration table is successfully imported.
MIRcatSDK_RET_NOT_INITIALIZEDif the system is not initialized.
MIRcatSDK_RET_PASSED_NULL_POINTERif any of the in parameters are null pointers.
MIRcatSDK_RET_QCL_NUM_OUTOFRANGEif the channel value is out of range of the channels.
MIRcatSDK_RET_TABLE_NUM_OUT_OF_RANGEif the table number is out of range.
MIRcatSDK_RET_COMM_ERRORif there is a communication error.

◆ MIRcatSDK_SetExtPreTrigMode()

uint32_t MIRcatSDK_SetExtPreTrigMode ( bool enabled)

Sets the External Pre Trigger mode.

if (enabled == true): Pre-trigger is the inverse to trigger (pre-trigger on whilst trigger is off; pre-trigger off whilst trigger is on). if (enabled == false): Pre-trigger acts accordingly to internal laser settings.

Parameters
enabledBoolean flag indicating whether external pre-trigger mode should be enabled.
Returns
Return Code indicating the status of setting the external pre-trigger mode.
Return values
MIRcatSDK_RET_SUCCESSif the external pre-trigger mode is successfully set.
MIRcatSDK_RET_NOT_INITIALIZEDif the MIRcat system is not initialized.
MIRcatSDK_RET_COMM_ERRORif unable to write the current external pre trigger mode.
