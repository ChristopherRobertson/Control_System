uint32_t MIRcatSDK_ConnectToDevice ( unsigned int handle)

Attempts to connect to the device labeled by the handle.

Parameters
handleHandle of the device the user wants to connect to.
Returns
Return Code indicating the status of the connection attempt.
Return values
MIRcatSDK_RET_SUCCESSif connecting to the device with the given handle is successful.
MIRcatSDK_RET_CONNECT_FAIL_AT_HANDLEif connecting to the device with the given handle is unsuccessful.

◆ MIRcatSDK_DisconnectFromDevice()

uint32_t MIRcatSDK_DisconnectFromDevice ( unsigned int handle)

Attempts to disconnect from the device given by the handle.

Parameters
handleHandle of the device the user wants to disconnect from.
Returns
Return Code indicating the status of the disconnection attempt.
Return values
MIRcatSDK_RET_SUCCESSif disconnecting from the device is successful.
MIRcatSDK_RET_NO_DEVICE_AT_HANDLEif finding the device given by the handle is unsuccessful.
MIRcatSDK_RET_NO_CONTROLLER_AT_HANDLEif the device given by the handle currently doesn't have a controller.
MIRcatSDK_RET_DISCONNECT_ERRORif disconnecting from the controller of the device given by the handler is unsuccessful.
