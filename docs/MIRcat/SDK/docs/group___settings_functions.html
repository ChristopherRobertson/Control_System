uint32_t MIRcatSDK_areCwFiltersInstalled ( uint8_t bQcl,
bool * pbFiltersInstalled )

Gets the status of CW filters being supported for the specified QCL.

Parameters
bQclQCL number indexed from 1-4.
[out]pbFiltersInstalledBool value that indicates if CW filters are installed on this channel.
Returns
Return Code indicating the status of checking if CW filters are installed.
Return values

MIRcatSDK_RET_PASSED_NULL_POINTERif the out parameter is a null pointer.

◆ MIRcatSDK_SetAllQclParams()

uint32_t MIRcatSDK_SetAllQclParams ( uint8_t bQcl,
float fPulseRate,
float fPulseWidth,
float fCurrentInMilliAmps,
float fTemperature,
uint8_t u8laserMode,
bool checkParams = true )

Sets the operating parameters for the specified QCL.

Parameters
bQclQCL number indexed from 1-4.
fPulseRatePulse rate in Hz.
fPulseWidthPulse width in nanoseconds (ns).
fCurrentInMilliAmpsCurrent in milliAmps (mA).
fTemperatureTemperature in degrees Celsius.
u8laserModeLaser Mode (Pulsed, CW, or CW+Mod).
checkParamsIf true, checks if the parameters are within range before setting them.
See also
Laser Modes
Returns
Return Code indicating the status of setting and saving the operating parameters for the specified QCL.
Return values
MIRcatSDK_RET_SUCCESSif the system successfully sets and saves the operating parameters for the specified QCL.
MIRcatSDK_RET_NOT_INITIALIZEDif the MIRcat controller is not yet initialized.
MIRcatSDK_RET_QCL_NUM_OUTOFRANGEif the user-specified QCL is out of range. Must be 1-4.
MIRcatSDK_RET_PULSERATE_OUTOFRANGEif the user-specified pulse rate is invalid and out of range.
MIRcatSDK_RET_PULSEWIDTH_OUTOFRANGEif the user-specified pulse width is invalid and out of range.
MIRcatSDK_RET_CW_NOT_ALLOWED_ON_QCLif the user-specified QCL does not support CW.
MIRcatSDK_RET_INVALID_LASER_MODEif the user specifies an invalid laser mode.
MIRcatSDK_RET_CURRENT_OUTOFRANGEif the user specifies a current that is out of range.
MIRcatSDK_RET_TEMPERATURE_OUT_OF_RANGEif the user specifies a temperature that is out of range.
MIRcatSDK_RET_SAVE_SETTINGS_FAILUREif the system fails to save the QCL settings.
