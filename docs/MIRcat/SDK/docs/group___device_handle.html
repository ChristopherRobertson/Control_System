Detailed Description

Functions and types for managing MIRcat device handles.

This group contains functions and type definitions for working with MIRcat device handles. Device handles are used to identify and communicate with connected MIRcat laser devices.

Macro Definition Documentation

◆ DLS_SCI_DEVICE_NULL_HANDLE

#define DLS_SCI_DEVICE_NULL_HANDLE   (0x0)

The null value for DLS_SCI_DEVICE_HANDLE.

This constant represents an invalid or null device handle. A connected device should never have this value. Use this to initialize handle variables or check for invalid handles.

◆ DLS_SCI_DEVICE_HANDLE

typedef unsigned int DLS_SCI_DEVICE_HANDLE

The device handle type for use with all functions that communicate with a connected device.

This type represents a unique identifier for a MIRcat device. It is used by all functions that need to specify which device to communicate with.
