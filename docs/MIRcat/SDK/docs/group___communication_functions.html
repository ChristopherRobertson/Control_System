◆ MIRcatSDK_CreateMIRcatObject()

uint32_t MIRcatSDK_CreateMIRcatObject ( )

Creates a new MIRcat object.

Deprecated
In single MIRcat mode, use MIRcatSDK_Initialize instead. In multi-MIRcat mode, use MIRcatSDK_ConnectToDevice instead.
Note
If a previous call has been made to MIRcatSDK_DeInitialize(), this function should be called before trying to call other MIRcatSDK functions.
Returns
Return Code indicating the status of creating the MIRcat object.
Return values
MIRcatSDK_RET_SUCCESSif creating a MIRcat object is successful.
MIRcatSDK_RET_ALREADY_CREATEDif the user attempts to create a new MIRcatObject when an instance has already been initialized.

◆ MIRcatSDK_DeInitialize()

uint32_t MIRcatSDK_DeInitialize ( )

Disconnect and clean up ports, memory, and threads associated with initializing the MIRcatSDK.

Note
In multi-MIRcat mode, use MIRcatSDK_DisconnectFromDevice instead.
Precondition
A call to this function requires a call to MIRcatSDK_CreateMIRcatObject() or MIRcatSDK_Initialize() before any subsequent calls to any SDK functions.
Returns
Return Code indicating the status of the de-initialization.
Return values
MIRcatSDK_RET_SUCCESSif de-initializing the MIRcat controller object was successful.
MIRcatSDK_RET_NOT_INITIALIZEDif the user tries to de-initialize the MIRcat object before the controller is initialized.

◆ MIRcatSDK_IsMIRcatObjectCreated()

uint32_t MIRcatSDK_IsMIRcatObjectCreated ( bool * pbMIRcatObjectCreated)

Returns a boolean value indicating if a MIRcat object has been created.

Deprecated
SDK calls already check if there is an active controller, and if there are none, those SDK functions return MIRcatSDK_RET_NOT_INITIALIZED.
Note
The object is destroyed following a call to MIRcatSDK_DeInitialize(). If it is destroyed, it must be created before any SDK function calls will be valid. A call to MIRcatSDK_Initialize() will also create the object if it has been destroyed.
Parameters
[out]pbMIRcatObjectCreatedTrue if the MIRcat object has been created; false otherwise.
Returns
Return Code indicating the status of checking the MIRcat object creation status.
Return values
MIRcatSDK_RET_SUCCESSif the system is successfully able to return a value.
MIRcatSDK_RET_PASSED_NULL_POINTERif the out parameter is a null pointer.
