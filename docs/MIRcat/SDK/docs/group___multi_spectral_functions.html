Adds a multi-spectral scan element to the end of the element list.

Parameters
fScanWWElement wavelength.
bUnitsElement wavelength units.
dwDwellTimeElement dwell time.
dwOffTimeElement off time.
Returns
Return Code indicating the status of adding an element to the end of the element list.
Return values
MIRcatSDK_RET_SUCCESSif the system successfully adds an element to the end of the element list.
MIRcatSDK_RET_NOT_INITIALIZEDif the MIRcat controller is not yet initialized.
MIRcatSDK_RET_INDEX_OUTOFBOUNDSif the user-specified element index (bIndex) is invalid and out of index bounds.
MIRcatSDK_RET_WW_OUTOFTUNINGRANGEif the user-specified wavelength is out of the valid range.
MIRcatSDK_RET_COMM_ERRORif the system is unable to read admin params or admin qcl params or unable to read status mask.

◆ MIRcatSDK_StartMultiSpectralModeScan()

uint32_t MIRcatSDK_StartMultiSpectralModeScan ( uint16_t wNumScans)

Starts a multi-spectral scan with the specified number of iterations.

Precondition
The elements for this scan must have been set up previously.
Parameters
wNumScansNumber of iterations for this multi-spectral scan.
Returns
Return Code indicating the status of starting the Multi-Spectral scan.
Return values
MIRcatSDK_RET_SUCCESSif the system successfully starts a Multi-Spectral scan.
MIRcatSDK_RET_NOT_INITIALIZEDif the MIRcat controller is not yet initialized.
MIRcatSDK_RET_LASER_NOT_ARMEDif the user attempts to start a multi-spectral scan before the laser is armed.
MIRcatSDK_RET_NOT_ENOUGH_ELEMENTSif the user does not define enough multi-spectral scan elements.
MIRcatSDK_RET_TECS_NOT_AT_SET_TEMPERATUREif the system is not operating at the set temperature.
MIRcatSDK_RET_START_MULTISPECTRALSCAN_FAILUREif the system fails to start a multi-spectral scan.
MIRcatSDK_RET_COMM_ERRORif the system is unable to read the status mask.
