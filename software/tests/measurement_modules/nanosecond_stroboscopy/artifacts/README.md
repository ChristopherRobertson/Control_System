# UI layout reference images

These images show the application with synthetic data or disconnected controls.
They are software layout references, not scientific measurements or hardware
qualification. Startup layout targets Segoe UI 9 at 1100 × 780 pixels, with
readable override fields, complete Save/Load controls and unclipped plot labels.

`single-startup-plan-actions-1100x780.png` and
`dual-startup-plan-actions-1100x780.png` show the startup forms.
`single-visible-overrides-1100x780.png` and
`dual-visible-overrides-1100x780.png` show detector-specific Auto overrides.
The remaining images illustrate compact panels, advanced controls and Phase Scan
plot layout. Tests use injected services and offscreen Qt; no image authorizes
hardware operation or establishes physical performance.
